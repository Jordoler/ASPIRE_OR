## MCPC-3D-S container
**Warning: This container is in active development**

The goal image-to-image container is to perform the MCPC-3D-S algorithm [[1]](#References) during reconstruction of a set of uncombined images. It has been designed to work with a T1w Grappa sequence, and it is recommended to do so.
**Note: this is container requires the technician to enable 'save uncombined' within the sequences program card**
